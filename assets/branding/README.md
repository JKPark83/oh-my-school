# 브랜딩 에셋 — 게임 아이콘 / 썸네일

크리에이터 대시보드 **콘텐츠 설정 → 아이콘·썸네일**에 올리는 「교장이 되어보자!」 이미지와 그 원본 소스다.
모두 HTML + CSS + 인라인 SVG로 그리고 헤드리스 Chrome으로 렌더링한다.
그래서 포토샵 없이 코드만 고쳐서 문구·색·구도를 바꾸고 다시 뽑을 수 있다.

## 파일

| 파일 | 크기 | 용도 |
|---|---|---|
| `icon.png` | 512×512 | 게임 아이콘. 학교 앞에서 두 팔을 든 꼬마 교장과 「교장」 금색 명패 |
| `thumbnail-a-campus.png` | 1920×1080 | 썸네일 A(학교 키우기). 초록 링 패드 위의 꼬마 교장, 땅에서 막 솟은 급식실, 시계탑 본관·체육관, 등교하는 전학생과 칭찬스티커 |
| `thumbnail-b-collection.png` | 1920×1080 | 썸네일 B(전학생 모으기). 전설 카드 코스모·금동이·백호를 앞줄에 두고 뒤에 평범·반장·전교1등 카드를 펼침 |

원본은 `src/` 아래 같은 이름의 `.html`이다. 캐릭터·제목·스티커 그리기는 세 파일이 `src/kit.js` 하나를 같이 쓴다.

## 다시 렌더링하기

```bash
cd assets/branding
./src/render.sh "$PWD/src/icon.html" "$PWD/icon.png" 512 512
./src/render.sh "$PWD/src/thumbnail-a-campus.html" "$PWD/thumbnail-a-campus.png" 1920 1080
./src/render.sh "$PWD/src/thumbnail-b-collection.html" "$PWD/thumbnail-b-collection.png" 1920 1080
```

- `render.sh`는 `/Applications/Google Chrome.app`을 `--headless=new --screenshot`으로 호출한다.
  인자 순서는 `<html 절대경로> <출력 png> <가로> <세로>`이다. HTML의 `html,body` 크기와 넘기는
  가로·세로가 다르면 그림이 잘리므로 두 값을 함께 고친다.
- 그림은 렌더링할 때 JS가 SVG 문자열을 만들어 `<svg id="art">`에 넣는 방식이다(`--virtual-time-budget=3000`).
  `kit.js`는 `<script src="kit.js">`로 불러오고, file:// 상대 경로로 읽힌다.
- `kit.js`를 고치면 세 장이 모두 바뀐다. 고친 뒤에는 세 장을 전부 다시 뽑아서 확인한다.

## kit.js

| 함수 | 하는 일 |
|---|---|
| `KIT.defs` | 공용 그라디언트(제목 노랑·흰색, 스티커, 금색, 헬멧 유리). 각 `<svg>`의 `<defs>`에 넣는다 |
| `KIT.chibi(o)` | 머리가 큰 꼬마. 원점은 두 발 사이 바닥이고 키는 약 306이다. 머리 모양·옷(`tee`/`blazer`/`space`/`tiger`/`gold`)·소품(모자·안경·머리핀·왕관·헬멧·호랑이 후드·메달·완장 등)·팔 각도·표정을 고를 수 있다 |
| `KIT.title(o)` | 제목 한 줄. 그림자 → 남색 외곽선 → 흰 테 → 색 글자 4겹이다 |
| `KIT.sticker(x,y,r)` | 칭찬스티커. 꽃잎 흰 테 + 노란 웃는 얼굴 |
| `KIT.sparkle` · `KIT.star` | 네 갈래 반짝임, 별 |

## 디자인 규칙

아이콘과 두 썸네일이 한 세트로 보이도록 아래 규칙을 함께 쓴다. 새 시안을 만들 때도 지킨다.
색은 기획서 §8.1 UI 색에서 가져왔다.

- **외곽선 `#2a2550`(남색)**: 모든 선과 글자 테두리에 쓴다. 검정보다 부드럽다.
- **노랑 `#FBBF24`·`#ffd43b`**: 제목 윗줄, 칭찬스티커, 별.
- **초록 `#34D399`**: 「다음 시설」 패드 링, A의 부제 띠.
- **하늘 `#46b1ff → #d9f3ff`**: 배경 하늘. 학교 벽은 크림 `#fff1d6`, 지붕·테두리는 주황 `#ff9b54`.
- **등급 색**: 평범 회색 `#9CA3AF`, 반장 파랑 `#60A5FA`, 전교1등 보라 `#A78BFA`, 전설 금색 `#F59E0B`.
  색만으로 구분하지 않도록 테두리 두께(평범 < 반장 < 전교1등 < 전설)와 등급 글자 칩, 별 1~4개를 함께 넣는다(기획서 §4 색각 접근성).
- **제목**: 「교장이」 노랑 + 「되어보자!」 흰색에 두꺼운 남색 외곽선을 두른다. 목록에서 200px로 줄어도 읽히게 하기 위해서다.
- **캐릭터**: 머리가 큰 귀여운 꼬마만 그린다. 실존 인물이나 실제 브랜드는 넣지 않는다.
- **칭찬스티커**: 동전처럼 보이면 안 된다. 숫자와 톱니 테두리 없이 웃는 얼굴 스티커로 그린다.
- **넣지 않는 것**(기획서 §12.2): Robux 기호, 가격, 보상을 약속하는 가짜 UI, 뽑기 기계·레버·릴·동전 투입구·잭팟 불빛 같은
  카지노 이미지, 빨강을 주색으로 쓰는 부정 표현, 긴 문장.

폰트는 macOS 기본 **Apple SD Gothic Neo**(font-weight 900)를 쓴다. 오프라인에서 쓸 수 있는 가장 굵은 한글 서체이기 때문이다.
그래서 다시 렌더링하려면 macOS + Chrome이 있어야 한다. 한글 디스플레이 폰트를 설치하면 `kit.js`와 세 HTML의 `font-family`를 바꿔
제목을 더 강하게 만들 수 있다.

## 업로드 전 확인

- **축소 확인**: 썸네일은 200px 폭, 아이콘은 100px로 줄여서 제목과 얼굴이 읽히는지 본다. 안 읽히면 글자나 인물을 키운다.
- **아이콘 모서리**: 로블록스는 아이콘 모서리를 둥글게 자른다. 중요한 요소는 가장자리에서 40px 안쪽에 둔다.
- **게임에 없는 요소는 넣지 않는다**: 지금 시안의 초록 링 패드, 솟아오르는 시설, 칭찬스티커, 전학생 이름과 등급(김하늘·이준서·채원·하율·코스모·금동이·백호),
  전학생 24명은 모두 기획서에 나오는 것이다.
- **캐릭터 모양**: 이미지 속 캐릭터는 공용 꼬마 그림이라 게임 안 메시와 똑같지는 않다. 최종 메시가 나오면 머리 모양·색을 맞춘다.
