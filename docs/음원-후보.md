## 0. 한 줄 결론

**분필·복도·삐걱·의자·긴장은 쓸 만한 무료(IsPublicDomain) 후보가 있고, 강의 중얼거림과 "야!" 호통은 못 찾았다.** 못 찾은 둘은 지시대로 지금 값(무음 / `uuhhh.mp3`)을 유지한다.

## 1. 검증 방법과 한계 (먼저 읽을 것)

- **IsPublicDomain**: 아래 표의 모든 ID 는 2026-09-27 Studio 에서 `GetProductInfo(id).IsPublicDomain == true`, `IsFree == true`, `PriceInRobux == 0` 을 확인했다. 표의 `IsPublicDomain` 열은 이 결과다. 확인 안 된 ID 는 표에 없다.
- **길이**: 스토어 설명의 길이가 아니라 Studio 에서 로드한 뒤 읽은 `TimeLength` 다(소수 첫째 자리 반올림). 설명과 0.1~0.5초 다를 수 있다.
- **★ 나는 한 개도 직접 듣지 않았다.** "루프 적합" 열은 (1) ProSoundEffects 설명에 `Loop` 표기가 있는지, (2) 길이가 루프에 충분한지, (3) 설명에 '반복되지 않는 단발 사건(bangs, drops, pick ups)'이 있는지로 **추정**한 것이다. 이음새는 귀로만 확인된다. 특히 분필은 이음새가 곧 규칙 오해라서, 고르기 전에 반드시 §9 방법으로 30초 이상 틀어 본다.
- 출처 표기: **PSE** = ProSoundEffects 무료 라이브러리(Roblox 계정 `ProSoundEffects`, 설명이 규격화되어 있어 신뢰도가 높다). **APM** = APMOfficial(APM Music). 그 외는 개인 업로드로, 이름만 믿을 수 있고 내용은 들어봐야 한다.
- 개인 업로드 중 IsPublicDomain=true 인 것도 내용이 이름과 다르거나 저작권 문제로 나중에 내려갈 수 있다. 중요한 소리(분필·긴장)는 PSE 쪽을 우선한다.

## 13. 들어 보는 방법 (Studio Command Bar, 코드 아님)

`SoundConfig` 를 건드리지 않고 Studio 에서만 듣는다. Command Bar 에 붙여 넣고 ID 만 바꾼다.

```lua
-- 루프 후보(chalk, hallway, tension): 30초 이상 듣고 이음새·반복 패턴을 확인한다
local s = Instance.new("Sound", workspace)
s.Name = "_Audition"
s.SoundId = "rbxassetid://9113781663"
s.Looped = true
s.Volume = 0.5
s:Play()
-- 끝나면: workspace._Audition:Destroy()
```

```lua
-- 원샷 후보(step, creak, chair, bell, whisper): 지금 코드가 쓸 speed 로 한 번 들어 본다
local s = Instance.new("Sound", workspace)
s.Name = "_Audition"
s.SoundId = "rbxassetid://9113774550"
s.PlaybackSpeed = 1.0
s.Volume = 0.6
s:Play()
s.Ended:Once(function() s:Destroy() end)
```

두 후보를 비교할 때는 이름을 `_Audition2` 로 바꿔 동시에 둔다. 분필 후보는 반드시 **선생님 위치에 파트를 하나 놓고 그 안에 Sound 를 넣어** 3D 로 들어 본다(2D 로 들으면 이음새가 덜 들린다).

## 14. 형이 결정할 것

1. **chalk**: Chalkboard 6 / 7 / 11 중 하나. 듣고 멈춤 구간이 있으면 전부 탈락 → 내장 유지. 채택 시 `speed` 1.7 → 1.0 부근.
2. **hallway**: Kids Walla(체육관 아이들) / Crowd Murmur(조용한 실내) / 그대로 SILENT. 채택 시 `speed` 0.4 → 1.0.
3. **lecture**: SILENT 유지 확인. 녹음·업로드로 규칙을 깰지.
4. **step**: 한 파일 공유(선택지 A) vs 세 파일(선택지 B) vs 내장 유지.
5. **creak / chair**: 각 1순위(Floor Creaks 11, Chair Movement 5) 채택 여부. 채택 시 `speed` → 1.0.
6. **scold**: 내장 유지 vs 녹음·업로드. 규칙을 깰 가치가 가장 큰 항목.
7. **bell**: 서양 전기 벨 vs 차임(limco chime 확인) vs 내장 유지. bell 을 바꾸면 **success/late 를 같이 바꿀지** 결정.
8. **tension**: 룸톤(가) / 드론(나) / 심장(다). 채택 시 `speed` 0.35 → 1.0, volume 0.16~0.25.
9. **whisper**: 아이 목소리 후보 채택 여부.

결정 후 바꾸는 파일은 `src/shared/Config/SoundConfig.luau` 하나, 바꾸는 줄은 `DEFS[key].id`(그리고 필요 시 같은 줄의 `speed`)뿐이다. 다른 파일을 건드려야 한다면 그건 이 문서의 범위를 넘는 별도 작업이다.
