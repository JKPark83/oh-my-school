# 아이 테스트 W9 관찰시트

아이 한 명을 30분 동안 볼 때 손에 들고 쓰는 시트다. 아이 3명(7·9·11세, 기획서 §13.1 7주 행)마다 한 장씩 뽑아 쓴다.
기준 문서는 개선계획 `docs/개선계획-2026-09-29-꾸미기-전환.md` §5 「아이 테스트에서 볼 것(W9)」, 기획서 §2.4(5분 완료 기준)·§5.7(다이얼)·§7.5(방문객)·§13.1 7·8주 행이다.
이 시트는 수치를 바꾸지 않는다. 결과를 모아 ⑤ 결정표에서 다이얼을 고르고, 값 변경은 기획서·시뮬(`docs/sim/`)과 같은 변경에서 한다.

## ① 준비

- [ ] **빌드**: 게시본(비공개 테스트 장소) 또는 Studio 「클라이언트 및 서버」 2클라. Studio 1인 Play 는 쓰지 않는다(2인 항목 ⑥ 을 못 본다).
  - Studio 는 `PrincipalProfile_Dev` + Mock 이라 매번 새 계정처럼 시작한다. 기존 계정을 보려면 게시본 또는 `UseLiveDataStore = true`.
  - 게시본에서는 `DevCheat` 가 꺼져 있다. 로그는 관찰자 계정이 같은 서버에 들어가 개발자 콘솔(F9) 「서버」 탭에서 본다(관찰자는 편집 권한이 있어야 서버 로그가 보인다).
  - **같은 서버에 들어가기**: 비공개 서버를 하나 만들어 아이 계정이 먼저 들어가고, 관찰자 계정은 같은 비공개 서버로 들어간다(아이 계정과 친구면 「참여」로 따라가도 된다). 관찰자 계정은 ⑥ 방문객 계정을 겸한다(서버에 계정 둘. 셋이 되면 로그가 섞인다).
  - **로그 받기**: 관찰 중에는 로그를 손으로 옮기지 않는다. 5분·30분·요약 줄이 찍히면 F9 화면을 스크린샷으로 찍고, 값은 테스트가 끝난 뒤 ④ 「적은 값」에 옮긴다. 로그는 아이 DisplayName 으로 시작하는 줄만 읽는다. 요약 줄은 아이가 나갈 때 찍히므로 관찰자 계정은 아이가 나갈 때까지 서버에 남는다.
- [ ] **기기**: 아이가 평소 쓰는 기기. 충전해 두고 화면 자동 꺼짐을 끈다. 모바일이면 812×375 급 가장 작은 폰이 가장 좋다.
- [ ] **소리 켜기**: 기기 볼륨 중간 이상, 게임 설정의 효과음(`sfx`) 켬. 부품 도장음·스티커 소리에 반응하는지 보는 테스트다. 아이가 스스로 소리를 끄면 그것도 적는다(④ 다이얼 「부품 연출 소리」).
- [ ] **화면 이름**: 화면에는 DisplayName 만 나온다. 기록에도 DisplayName 과 로그의 UserId 숫자만 쓰고 실명·Username 은 적지 않는다.
- [ ] **관찰자 규칙**: 말해 주지 않는다. 아이가 물으면 「어떻게 하면 될 것 같아?」로 돌려준다. 손으로 화면을 가리키지 않는다. 60초 넘게 완전히 멈추고 도움을 청하면 그때만 한 번 돕고, 도운 시각과 내용을 적는다(도운 항목은 「통과」에 표시하지 않는다).
- [ ] **2인 테스트용 두 번째 계정**(⑥): 어른이 방문객 역할. 아이 부지와 이웃한 부지로 들어온다.
- [ ] 시계(스톱워치) 하나. 게임 시작 순간을 0:00 으로 둔다. 로그의 시각은 서버 세션 시작(부지 할당 직후) 기준이라 몇 초 차이 날 수 있다.

## ④ 로그 판독표

서버 로그 줄 형식(값이 없으면 `-`):

```
[Metrics] {DisplayName}({UserId}) 5분 · 부품 {p}(≥24) · 시설 {f} · 미션 {m}(≥2) · 선물 {g}(≥1) · 꾸미기 {d}(≥1) · 첫 배치 {m:ss|-} · 버튼 첫 탭 {m:ss|-} · 부품 간격 중앙값 {N}초(최대 {M}초, {n}회) → 통과|미달 · 새 계정|기존 계정
[Metrics] {DisplayName}({UserId}) 30분 · 시설 {f}/14 · 누적 졸업 {n}회(이번 세션 {k}) → 통과|미달 · 새 계정|기존 계정
[Metrics] {DisplayName}({UserId}) 요약 · {계정} · 세션 m:ss · 회수율 … · 5분 … · 30분 … · 패드 3초 미만 … · 부품 간격 중앙값 N초(최대 M초, n회) · 리스폰→줍기 중앙값 N초(n회) · 꾸미기 첫 배치 m:ss · 버튼 첫 탭 m:ss
```

- 요약 줄의 「…」 자리: `회수율 {P%|-}(주움 {c} / 기회 {k})` · `5분 통과|5분 미달|5분 전 종료` · `30분 시설 {x}/14{(졸업 n회)}|30분 전 종료` · `패드 3초 미만 {n}회(살 돈 있었음 {a})`.
- 목록이 비면 괄호 없이 `부품 간격 중앙값 -`·`리스폰→줍기 중앙값 -` 로 찍힌다. 중앙값은 짝수 개면 가운데 둘의 평균을 반올림한 정수 초다.
- Studio 의 `DevCheat.MetricsNow` 는 같은 내용을 `[Metrics] {DisplayName}({UserId}) 지금까지 요약 · …` 로 찍는다. 이 줄의 「5분 전 종료」·「30분 전 종료」는 아직 5:00·30:00 이 안 됐다는 뜻이다(세션은 끝나지 않았다).

실제 줄 예(2026-09-30 Studio 통합 게이트, 치트로 3분 만에 14시설을 돌린 것이라 값 자체는 아이 기준이 아니다. 이름·UserId 는 가렸다. 리스폰→줍기 32초는 부품을 사서 새로 켜진 스폰까지 세던 수정 전 코드의 값이다. 층 구매·엘리베이터·층 체류 항목은 2026-10-01 층 올리기 폐기로 요약 줄에서 빠졌고 아래 예에서도 지웠다):

```
[Metrics] 교장님(1234) 요약 · 새 계정 · 세션 3:21 · 회수율 5%(주움 4 / 기회 81) · 5분 전 종료 · 30분 전 종료 · 패드 3초 미만 0회(살 돈 있었음 0) · 부품 간격 중앙값 1초(최대 31초, 50회) · 리스폰→줍기 중앙값 32초(4회) · 꾸미기 첫 배치 3:04 · 버튼 첫 탭 2:00
```

5분 줄의 「통과」는 부품 ≥ 24 · 미션 ≥ 2 · 선물 ≥ 1 · 꾸미기 ≥ 1 네 기준을 모두 넘었다는 뜻이다(기획서 §2.4).

| 항목(줄) | 뜻 | 기준 | 미달이면 볼 곳(⑤ 다이얼 또는 기획서 절) | 적은 값 |
|---|---|---|---|---|
| 부품 {p}(≥24) (5분) | 5:00 에 산 부품 수(프로필 값) | ≥ 24(`FIVE_PARTS`, 시뮬 활동형 28) | 발자국·빛기둥 노출(§2.4). 회수율이 낮으면 RESPAWN | |

| 미션 {m}(≥2) (5분) | 이번 세션에 끝낸 일일 미션 수 | ≥ 2(`FIVE_MISSIONS`) | 교장 의자 유도(튜토리얼) | |
| 선물 {g}(≥1) (5분) | 이번 세션에 열린 선물판 선물 수 | ≥ 1(`FIVE_GIFTS`) | §13.3 「선물판을 모름」 행 | |

| 첫 배치 m:ss (5분·요약) | 세션 시작부터 첫 꾸미기 배치까지 | 5:00 안 | 위와 같음 | |
| 버튼 첫 탭 m:ss (5분·요약) | 세션 시작부터 HUD 「꾸미기」 버튼 첫 탭까지(`UiMark` "decorTap") | 튜토리얼 ⑤ 직후. 첫 배치보다 한참 앞이면 시트 안에서 헤맨 것 | 탭이 늦으면 버튼 글자, 탭 뒤 배치가 늦으면 배치 조작·✕ | |
| 부품 간격 중앙값 N초(최대 M초, n회) (5분·요약) | 부품 구매 사이 간격(첫 값은 세션 시작부터) | 시뮬 최대 간격 55초. 최대가 60초를 넘으면 관찰표 「1분 넘게 멈춤」과 맞춰 본다 | 초반이면 발자국·빛기둥, 후반이면 STICKER_SECONDS | |
| 회수율 N%(주움 / 기회) (요약) | 주운 스티커 ÷ (켜진 스폰 수 × 초 ÷ 15) | ≥ 40%(§13.1 7주, 시뮬 가정 55%) | RESPAWN 15 → 12, 빛기둥 노출(§13.3) | |
| 5분 통과·미달 / 30분 시설 {f}/14 (요약·30분) | 위 5분 판정, 30:00 의 시설 수(이번 세션에 졸업했으면 14/14 로 본다) | 30분 14/14(1회차 활동형 17:18) | 25분을 넘기면 회수율이 낮을 때 RESPAWN 15 → 12(§5.7, ⑤ 첫 행), 회수율이 정상이면 STICKER_SECONDS 1.2 → 1.5(§13.3, ⑤ 둘째 행) | |
| 패드 3초 미만 n회(살 돈 있었음 k) (요약) | 패드에 올라섰다가 3초 안에 사지 않고 내려온 횟수 | 적을수록 좋음. k 가 크면 「서 있으면 산다」를 모름 | 패드 판정 반경·말풍선(§13.3) | |

## ⑥ 2인 테스트(방문객이 주인을 방해하지 않는지)

기획서 §7.5 점검표를 그대로 본다. 아이가 주인, 어른이 방문객.

| 확인 | 방법 | ○ / ✕ |
|---|---|---|
| 패드(주인만) | 방문객이 아이의 다음 패드 위에 서 있어도 아이가 올라서면 산다 | |
| 스티커(주인만) | 방문객이 아이 스티커를 밟아도 아무 일 없음 | |
| 별(방문객만) | 방문객이 별을 밟으면 방문객에게만 사라짐. 아이 화면·용돈 변화 없음 | |
| 팻말·졸업 종·교장 의자(주인만) | 방문객이 눌러도 반응 없음, 교장 의자에 앉지 못함 | |
| 문·교문·캐릭터(충돌 없음) | 방문객이 교문·계단 앞을 막아도 아이가 지나감 | |
| 연출·소리(주인 화면만) | 방문객이 꾸미기 시트·선물 연출을 보지 않음 | |
| 꾸미기 보기 | 방문객 화면에서 아이가 꾸민 소품이 보임 | |
| 아이의 느낌 | 「누가 방해했어」 같은 말이 없음 | |
