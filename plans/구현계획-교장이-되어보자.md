## 3. 모듈 간 계약

### 3.1 공용 (shared) — P0 가 실제 코드로 고정

- `Keys`: 태그·어트리뷰트·인스턴스 이름 문자열 상수. 문자열 리터럴을 코드에 직접 쓰지 않는다.
- `Types`: `Profile`, `Facility`, `Student`, `Skin`, `GameEventKind`, `PlotId = number`, `FacilityId = string`, `StudentId = string`.
- `FacilityConfig.ORDER: {FacilityId}` (구매 순서), `FacilityConfig.BY_ID`, 각 행은 §3.1 (`price, income, student, center, size, pad, door, seats, spawns`). `FacilityConfig.priceOf(id, graduations)`.
- `StudentConfig.BY_ID`, `.ORDER`, 각 행 §4.1 (`name, tier, contrib, mesh, fallbackVariant, tint, prop, seat = {facilityId, index}, unlock = {kind = "facility"|"graduation"|"gacha", value}`).
- `GachaConfig`: `RATES`, `PITY`, `DUPE_CELLS`, `unlockedPool(graduations): {StudentId}`.
- `EconomyConfig`: §5.1 상수. `incomePerSecond(profile)`, `multiplier(profile)`, `stickerValue(profile)`, `startCoins(graduations)`, `spawnCount(#facilities)`.
- `Seats.seatOf(studentId, builtFacilities: {[FacilityId]: true}) → {facilityId, index}?` 순수 함수.
- `Format.coins(n)`, `Format.income(n)`, `Format.multiplier(x)`.
- `Remotes`: 서버 `Remotes.init()`, 클라 `Remotes.wait()`; 이후 `Remotes.SetSkin` 등 7개 RemoteEvent 필드. 서버 헬퍼 `Remotes.event(player | nil, kind, payload)` = `GameEvent` 발송(nil → 전원).
- `CharacterBuilder`: `preload()`(서버, 실패 변형은 warn 후 건너뜀), `build(name, base, config)`, `setHandRaised`, `studentConfig(studentId)`, `variantFor(studentId)`(없는 메시 → fallbackVariant). 센서 Head 없음.

### 3.2 서버 서비스 API

```lua
DataService
  .Start()                              -- 스토어 준비
  .load(player) -> Profile?             -- 실패 시 Kick
  .get(player) -> Profile?
  .save(player)                         -- 즉시 저장
  .saveDebounced(player, seconds)
  .release(player)
  .markDirty(player)                    -- ProfileSync 예약 (≤1Hz, seq 단조)
  .syncNow(player)                      -- 즉시 ProfileSync

PlotService
  .Start()                              -- Workspace.Plots / ReplicatedStorage.PlotState 확인, Touched 배선, 팻말/경계 처리
  .assign(player) -> plotId             -- 빈 번호 중 최소
  .release(player)
  .plotOf(player) -> plotId?
  .ownerOf(plotId) -> Player?
  .cframe(plotId) -> CFrame
  .folder(plotId) -> Model              -- Workspace.Plots.PlotNN
  .state(plotId) -> Folder              -- ReplicatedStorage.PlotState.PlotNN
  .syncAttributes(player)               -- 프로필 → 7개 어트리뷰트
  .buildFacility(player, facilityId)    -- Geometry 삽입(Transparency 1 + Built), 패드/실루엣/스폰 갱신
  .teardown(player)                     -- 졸업: 시설 모델 제거, 스폰 3, 실루엣
  .goHome(player)
  .lock(player, locked: boolean)        -- 졸업 처리 중 입력 무시 플래그
  .isLocked(player) -> boolean
  .onPad: Signal(player, facilityId)    -- 패드 위 1Hz 체크는 EconomyService 가 PlotService.occupants(player) 로 읽는다
  .occupants(player) -> {[FacilityId]: true}   -- 현재 밟고 있는 패드

EconomyService
  .Start()                              -- 1Hz 틱: 수입, 패드 자동 구매, 스티커 리스폰, SetSkin 핸들러
  .grant(player, amount)                -- 용돈 지급 + markDirty
  .onSticker(player, part)              -- PlotService 가 Touched 를 넘긴다
  .onStar(player, plotId, part)

StudentService
  .Start()                              -- preloadPrototypes 는 init.server 가 task.spawn, RollGacha 핸들러
  .grant(player, studentId, walk)       -- 프로필 반영 + Students 어트리뷰트 + StudentJoined
  .roll(player) -> GachaResult?         -- 원서 없으면 nil

MissionService
  .Start()                              -- 60s ensureDay 틱, 의자 Occupant 감시
  .ensureDay(profile)
  .onSticker(player, count)  .onBuilt(player)  .onChair(player)

GraduationService
  .Start()                              -- Graduate 핸들러. 흐름은 §6.1
LeaderboardService
  .Start()  .submit(player, graduations)

RemoteGuard
  .wrap(remote, opts: {cooldown: number, args: {string}}, handler: (player, ...) -> ())
  .violation(player, reason)
DevCheat  (Studio 전용)  .fastForward(player, seconds)  .giveTickets(player, n)
```

의존 방향(순환 금지): Data ← Plot ← Student ← Economy ← Mission; Graduation → Data/Plot/Student/Leaderboard/Mission; Economy/Student 는 `PlotService.isLocked` 로 졸업 중을 판정한다.

### 3.3 Geometry 계약

`src/server/Geometry/<facilityId>.luau` → `{ build = function(plotCFrame: CFrame, skinIndex: number): Model }`. 모델 이름 = facilityId, 파트 ≤25, 전부 `BuildKit.part`, 벽·지붕 `fade = true`, `Seats` 폴더에 Attachment `S01…`(앉는 면 중심, -Z 가 얼굴), 문 폭 ≥8. `PlotShell.build(plotCFrame): Model` = 현관·교실1·담장·교문·스폰·패드 14개·스티커 스폰 8개·별 2개·팻말·접수대·2층 착지대·「공사 중」실루엣. `Plaza.build(): Model` = 조회대·팻말·리더보드·게시판·벤치.

### 3.4 클라이언트 컨트롤러 계약

각 컨트롤러 `Start()` 한 번. 상태 공유는 `ReplicatedStorage.PlotState` 어트리뷰트 + `ProfileSync` 로컬 캐시(`HudController.profile()`)로만 한다. 컨트롤러끼리는 다음 함수만 부른다:

```lua
HudController.profile() -> Profile?      HudController.onProfile(fn)      HudController.toast(text)  .banner(text)
PanelController.open(name, payload?)     PanelController.close()
FeedbackController.play(kind, payload)   -- §9.2 표의 kind
SoundController.play(key)  .setMuted
CameraController.panTo(worldPos, seconds)  .shake(trauma)  .fovPunch()  .orbit(...)  .restore()
TransitionController.fadeTo(alpha, seconds)  .cut()
TutorialController.stage() -> number
```

`init.client.luau` 가 순서대로 Start 하고 `GameEvent` 를 한 곳에서 받아 kind 별로 위 함수에 분배한다.

### 3.6 Geometry 빌더 규약

- `build(plotCFrame: CFrame, skinIndex: number): Model`. 모델 이름 = facilityId. 좌표는 `FacilityConfig.BY_ID[id]` 의 center/size/pad 를 쓴다(부지 로컬). 월드 변환: `local cf = plotCFrame * CFrame.new(localPos) * localRot` → `BuildKit.part(parent, name, size, cf.Position, { cframe = cf.Rotation, ... })`.
- 파트 ≤25, 전부 `BuildKit.part`. 벽·지붕은 `fade = true`. `CanQuery` 는 기본값.
- 스킨: `SkinConfig.get(id, skinIndex)` 의 primary/secondary/material 을 쓰는 파트에 어트리뷰트 `SkinRole = "primary" | "secondary"` 를 둔다(클라가 스킨 변경 때 재조립 없이 다시 칠한다). 재질도 그 파트에 적용.
- 좌석: `Seats` 폴더에 Attachment `S01…`. 위치 = 의자 아래 **바닥** 중심(방 바닥 높이), LookVector(-Z) = 학생이 보는 방향. 의자 앉는 면 높이 1.55, 책상 상판 2.875 (`CharacterBuilder.SIT_HIP/SIT_DESK`).
- 좌석이 있는 모델은 Attachment `Door` 하나(문 중심 바닥, LookVector 가 방 안쪽). desk 모델의 Door 는 교실1 남문 (-60,0,-32.5).
- 시설마다 Attachment `SkinSign` 하나(페인트 롤러 팻말 위치, 눈높이).
- principal: Roblox `Seat` 인스턴스 "PrincipalChair" (60,-10) 앉는 면 1.55, Disabled=false. 손님 자리 S01 (50,-2.5).
- auditorium: 바닥 y=18, 좌석 S01…S25(S25 예약), 단상 (0,-32.5) 위 Part "GraduationBell".
- 문 폭 ≥8. 벽 두께 1, 높이 18(방, 체육관 20), 지붕 두께 1. 미건설 부지는 평평한 바닥(Shell 바닥이 이미 있으므로 아무것도 안 둔다).

### 3.7 클라이언트 배선(init.client 이 GameEvent 를 분배)

| kind | 받는 쪽 |
|---|---|
| FacilityBuilt | FeedbackController.play("purchase"), PadController.refresh(), TutorialController.refresh() |
| StudentJoined | StudentRenderController.onStudentJoined(payload), FeedbackController.play("student", payload) |
| GachaResult | PanelController.onGachaResult(payload) |
| MissionDone | FeedbackController.play("mission", payload), HudController.refresh() |
| Graduated | FeedbackController.play("graduated", payload) (본인 = 졸업식 §9.5, 타인 = 색종이) |
| SkinApplied | PadController.applySkin(payload) (SkinRole 파트 재도색 + 반짝) |
| StickerCollected | FeedbackController.play("sticker", payload), PadController.confirmSticker(payload) |
| Deny | FeedbackController.play("deny", payload) |

`ProfileSync` 는 HudController.setProfile(packet) 하나만 받고, 나머지는 `HudController.onProfile(fn)` 로 구독한다.
