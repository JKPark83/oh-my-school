## 3. 모듈 간 계약

### 3.1 공용 (shared) — P0 가 실제 코드로 고정

- `Keys`: 태그·어트리뷰트·인스턴스 이름 문자열 상수. 문자열 리터럴을 코드에 직접 쓰지 않는다.
- `Types`: `Profile`(v2: `stickerBoard`·`giftIndex`·`decorOwned`·`decorPlaced: {DecorPlacement}`·`decorPaid`(돌려주기용 산 값 스택)·`decorStarter`(튜토리얼 화분 지급 여부)·`towerFloors`, W4 에서 `tickets`·`pity`·`stats.totalPulls` 삭제), `DecorPlacement = {item, cx, cz, rot, f?}`, `Facility`, `Student`, `GameEventKind`(W5: `DecorPlaced{slot, item, cx, cz, rot, f, moved}`·`DecorStored{slot, item}`·`DecorBought{item, coins, student?}`·`DecorReturned{item, coins}`, 모두 본인에게만), `GiftOpened = {giftIndex, kind = "coins" | "item", coins, item?, boardCells}`(item 이면 coins 0), `PlotId = number`, `FacilityId = string`, `StudentId = string`.
- `FacilityConfig.ORDER: {FacilityId}` (구매 순서), `FacilityConfig.BY_ID`, 각 행은 §3.1 (`parts: {number}`(부품 가격, 기획서 부록 B 표), `income, student, center, size, pad, door, seats, spawns`). `FacilityConfig.PART_COUNT = 50`, `partCount(id)`, `partPriceOf(id, k, graduations)` = floor(parts[k] × 1.35^graduations + 0.5), `nextPartOf(built, buildParts) -> {facility, index, count}?`, `partsBuilt(profile)`.
- `StudentConfig.BY_ID`, `.ORDER`, 각 행 §4.1 (`name, tier, contrib, mesh, fallbackVariant, tint, prop, seat = {facilityId, index}, unlock = {kind = "facility"|"graduation"|"friend", value}`). `"friend"` 는 졸업 n회부터 친구 아이템이 상점에 진열된다(`DecorConfig` 의 친구 아이템 `unlock` 과 같은 값).
- `EconomyConfig`: §5.1 상수. `incomePerSecond(profile)`, `multiplier(profile)`, `stickerValue(profile)`, `startCoins(graduations)`, `BOARD_CELLS = 40`, `GIFT_COIN_VALUE`, `giftCoins(graduations)`, `spawnCount(facilities, buildParts)`(기본 3 은 책상 첫 부품을 산 뒤부터 켠다. 기획서 §3.1).
- `Seats.seatOf(studentId, builtFacilities: {[FacilityId]: true}) → {facilityId, index}?` 순수 함수.
- `Format.coins(n)`, `Format.income(n)`, `Format.multiplier(x)`.
- `Remotes`: 서버 `Remotes.init()`, 클라 `Remotes.wait()`; 이후 `Remotes.Graduate` 등 10개 RemoteEvent 필드(클→서 `Graduate`·`SetSetting`·`GoHome`·`BuyDecor`·`PlaceDecor`·`MoveDecor`·`StoreDecor`·`ReturnDecor`, 서→클 `ProfileSync`·`GameEvent`). 서버 헬퍼 `Remotes.event(player | nil, kind, payload)` = `GameEvent` 발송(nil → 전원), `Remotes.deny(player, reason)`(reason `coins`·`cooldown`·`owner`·`cell`·`limit`·`owned`·`locked`).
- `PlotLayout`(W5 추가): `CELL = 5`, `GRID = 30`, `cellCenter(cx, cz) -> Vector2`(부지 로컬, -75 + c×5 + 2.5), `cellOf(x, z) -> (cx, cz)`(0..29 로 clamp), `DECOR_STATIC`(PlotShell 고정물 사각형 목록).
- `DecorConfig`(W5): `CELL`·`GRID`·`MAX_PLACED = 40`·`MAX_OWNED = 10`·`TUTORIAL_ITEM = "planter"`·`TUTORIAL_FREE = 2`, `LIST`(27행, 순번 = `indexOf` 1..27), `BY_ID`, `byId(id)`, `indexOf(id)`, `GIFT_ORDER`, `giftAt(giftIndex) -> itemId?`, `priceOf(id, graduations)` = floor(price × 1.35^N + 0.5), `isShown(item, graduations)` = 선물 아님 ∧ N ≥ unlock, `heldCount(owned, placed, id)`. 행 필드 `id`(≤10자)·`name`(≤6자)·`kind`(general·friend·gift)·`price`·`unlock`·`student?`·`w`·`d`·`parts`(≤6). 로드 시 assert.
- `DecorCodec`(W5): `encode(placed) -> string`, `decode(text) -> {DecorPlacement}`. 형식은 기획서 §11.4 `Decor`(항목 = 순번 2 + cx 2 + cz 2 + rot 1 + f≠1 일 때 f, 끝 `;`, ≤ 440 바이트). decode 는 모르는 순번·범위 밖 값을 건너뛴다.
- `DecorGrid`(W5, 서버·클라 공용 순수 함수): `size(itemId, rot)`, `footprint(itemId, cx, cz, rot) -> {Vector2}`(rot 1·3 이면 w·d 교환, 원점에서 +x·+z), `footprintCenter`, `isStaticBlocked(cx, cz)`, `isFloorBlocked(f, cx, cz)`, `canPlace(placed, towerFloors, itemId, cx, cz, rot, f, ignoreSlot?) -> (boolean, reason)`(reason `ok`·`item`·`cell`·`floor`·`blocked`·`overlap`·`limit`, 이 순서로 검사), `blockers(...)`, `nearestFree(...)`(맨해튼 ≤ 6).
- `DecorBuilder`(W5, 클라가 쓴다): `build(item, cframe, {ghost}?) -> Model`. Anchored, CanCollide·CanTouch false.
- `CharacterBuilder`: `preload()`(서버, 실패 변형은 warn 후 건너뜀), `build(name, base, config)`, `setHandRaised`, `studentConfig(studentId)`, `variantFor(studentId)`(없는 메시 → fallbackVariant). 센서 Head 없음.

### 3.2 서버 서비스 API

```lua
DataService
  .Start()                              -- 스토어 준비
  .load(player) -> Profile?             -- 실패 시 Kick
  .get(player) -> Profile?
  .save(player)                         -- 즉시 저장
  .saveDebounced(player, seconds)
  .release(player)
  .markDirty(player)                    -- ProfileSync 예약 (≤1Hz, seq 단조)
  .syncNow(player)                      -- 즉시 ProfileSync

PlotService
  .Start()                              -- Workspace.Plots / ReplicatedStorage.PlotState 확인, Touched 배선, 팻말/경계 처리
  .assign(player) -> plotId             -- 빈 번호 중 최소
  .release(player)
  .plotOf(player) -> plotId?
  .ownerOf(plotId) -> Player?
  .cframe(plotId) -> CFrame
  .folder(plotId) -> Model              -- Workspace.Plots.PlotNN
  .state(plotId) -> Folder              -- ReplicatedStorage.PlotState.PlotNN
  .syncAttributes(player)               -- 프로필 → 8개 어트리뷰트(Decor 는 DecorService.refreshAttribute, TowerFloors 는 여기서)
  .buildPart(player, facilityId, k)     -- 임시로 build 한 모델에서 PartIndex==k 파트만 실제 모델로 옮김. 어트리뷰트 Parts=k, 마지막 부품이면 Built=true. 패드/실루엣/스폰 갱신
  .refreshSilhouette(plotId, built, buildParts)  -- 다음 시설의 안 산 부품만 실루엣(부지당 1개 이하)
  .teardown(player)                     -- 졸업: 시설 모델 제거, 스폰 0(책상 첫 부품에 3), 책상 실루엣
  .goHome(player)
  .lock(player, locked: boolean)        -- 졸업 처리 중 입력 무시 플래그
  .isLocked(player) -> boolean
  .onPad: Signal(player, facilityId)    -- 패드 위 1Hz 체크는 EconomyService 가 PlotService.occupants(player) 로 읽는다
  .occupants(player) -> {[FacilityId]: true}   -- 현재 밟고 있는 패드
  .onTowerPad(player) -> boolean       -- W6. 주인이 Tower 폴더의 TowerPad 위인가(시설 패드와 같은 isOver HRP 판정)
  .teleport(player, cf, waitStream?)   -- 서버 순간이동 한 곳(goHome·엘리베이터·졸업 대피). 뒤에 Teleported 를 쏜다
  .Teleported: RBXScriptSignal(player)
  -- 엘리베이터(W6): Tower 폴더 ElevatorNN 의 Up/Down 프롬프트 PromptTriggered → 서버 판정(기획서 §3.4) → teleport(Tower.arrival, false) → ElevatorRide(탄 사람). 리모트 아님
  -- 졸업 대피(W6): teardown 직전, 부지 로컬 Y > TowerConfig.EVACUATE_Y 인 주인·방문객을 1층 스폰으로 teleport

EconomyService
  .Start()                              -- 1Hz 틱: 수입, 패드 자동 구매(틱당 부품 1개 → PartBuilt, 마지막 부품이면 FacilityBuilt), 14/14 뒤 층 패드 자동 구매(W6, 틱당 1층, TowerConfig.priceOf → towerFloors += 1 → FloorBuilt 주인에게만), 스티커 리스폰
  .grant(player, amount)                -- 용돈 지급 + markDirty
  .onSticker(player, part)              -- PlotService 가 Touched 를 넘긴다
  .onStar(player, plotId, part)

StudentService
  .Start()                              -- preloadPrototypes 는 init.server 가 task.spawn
  .grant(player, studentId, walk)       -- 프로필 반영 + Students 어트리뷰트 + StudentJoined

MissionService
  .Start()                              -- 60s ensureDay 틱, 의자 Occupant 감시
  .ensureDay(profile)
  .onSticker(player, count)  .onBuilt(player)  .onChair(player)

DecorService   (W5, 8번째 서비스. 부팅은 Economy 뒤, Mission 앞)
  .Start()                              -- BuyDecor·PlaceDecor·MoveDecor·StoreDecor·ReturnDecor 를 RemoteGuard.wrap(cooldown 0.2)으로 받는다. 판정은 기획서 §5.8, 거부는 Remotes.deny 만(violation 안 부름)
  .refreshAttribute(player)             -- decorPlaced → DecorCodec.encode → PlotState Decor. 졸업 teardown 때는 비우지 않고 부지 반납 때만 ""

GraduationService
  .Start()                              -- Graduate 핸들러. 흐름은 §6.1(decorOwned·decorPlaced 는 그대로 둔다)
LeaderboardService
  .Start()  .submit(player, graduations)

RemoteGuard
  .wrap(remote, opts: {cooldown: number, args: {string}}, handler: (player, ...) -> ())
  .violation(player, reason)
DevCheat  (Studio 전용)  .fastForward(player, seconds)  .giveCoins(player, n)  .giveDecor(player, itemId, n) -> 보유 수  .giveFloors(player, n) -> 맞춘 층 수(W6, 0..MAX-2)  RideElevator(player, prompt) -> 옮겼나(W6 게이트, PlotService.rideElevator)

-- 서비스가 아닌 서버 모듈(W4)
GiftBoard  .settleBoard(player, profile) -> number   -- stickerBoard ≥ 40 인 동안 선물을 연다(giftIndex += 1, GiftOpened). DecorConfig.giftAt 이 소품이면 decorOwned += 1(kind "item", coins 0), 아니면 또는 MAX_OWNED 에 닿았으면 코인 giftCoins. Economy(스티커·별)·Mission(미션 완료)이 부른다
Migrations [이전 버전] = (data) -> ()               -- 순수 함수. DataService 가 Reconcile 뒤 SCHEMA_VERSION(2)까지 돌린다
```

의존 방향(순환 금지): Data ← Plot ← Student ← Economy ← Mission; GiftBoard 는 Data·Remotes·EconomyConfig·Metrics 만 require 하고 Economy·Mission 이 부른다; Graduation → Data/Plot/Student/Leaderboard/Mission; Economy/Student 는 `PlotService.isLocked` 로 졸업 중을 판정한다; Decor → Data/Plot/Student(친구 아이템 grant). ### 3.3 Geometry 계약

`src/server/Geometry/<facilityId>.luau` → `{ build = function(plotCFrame: CFrame): Model }`. 모델 이름 = facilityId, 파트 ≤25, 전부 `BuildKit.part`, BasePart 마다 `PartIndex` 1..부품 수(1 바닥·벽, 2 지붕·문틀, 3·4 가구, `BuildKit.assertPartIndex(model, count)`), 벽·지붕 `fade = true`, `Seats` 폴더에 Attachment `S01…`(앉는 면 중심, -Z 가 얼굴), 문 폭 ≥8. `PlotShell.build(plotCFrame): Model` = 현관·교실1·담장·교문·스폰·패드 14개·스티커 스폰 8개·별 2개·팻말·접수대 건물(프롬프트 없음)·2층 착지대·「공사 중」실루엣. `Plaza.build(): Model` = 조회대·팻말·리더보드·게시판·벤치·나무 9·화단 ≤ 2(W8)·Creator Store 모델 ≤ 3(W8). `PropLibrary`(W8) = `tree(parent, cframe, seed) → Model`(메시 id 있으면 MeshPart 1개 `WorldPalette.leaf`, 없으면 `Tree.build` 위임) · `flowerbed(parent, cframe, seed) → Model`(메시 없으면 파트 ≤ 4) · `storeModel(parent, entry, cframe) → Model?`(`InsertService:LoadAsset` pcall, 실패 nil, 스크립트 전부 Destroy, Anchored·CanCollide false, 파트 수 ≠ `entry.parts` 면 warn). 교실형 7(class2·cafeteria·library·nurse·science·music·principal)은 박공지붕 WedgePart 2(파트 25 를 넘으면 평지붕 유지), gym 은 아치, 문 없는 바깥벽에 창 `Texture`(`PropAssets.WINDOW_TEXTURE.id` 0 이면 없음). `Tower.refresh(plotModel, plotCFrame, towerFloors, hasAuditorium)`(W6) = 부지 모델 안 `Tower` 폴더를 다시 짓는다(강당이 없으면 비움): 층 바닥판 3..2+towerFloors(FADE, 어트리뷰트 Floor)·엘리베이터 앵커 ElevatorNN(2층~꼭대기, Up/Down 프롬프트는 앵커 안 Attachment 위·아래에 따로)·TowerPad·지붕. 서버 파트 2n+3(n = 0 이면 지붕이 없어 2). `Tower.ghost(plotCFrame, n)` = 다음 층 실루엣(Silhouette 슬롯), `Tower.arrival(plotCFrame, n)` = 도착 자리(3층부터 앵커 남쪽 칸, 2층은 층 패드를 피해 북쪽 칸 `PlotLayout.ELEVATOR_ARRIVAL_2`).

### 3.6 Geometry 빌더 규약

- `build(plotCFrame: CFrame): Model`. 모델 이름 = facilityId. 좌표는 `FacilityConfig.BY_ID[id]` 의 center/size/pad 를 쓴다(부지 로컬). 월드 변환: `local cf = plotCFrame * CFrame.new(localPos) * localRot` → `BuildKit.part(parent, name, size, cf.Position, { cframe = cf.Rotation, ... })`.
- 파트 ≤25, 전부 `BuildKit.part`. 벽·지붕은 `fade = true`. `CanQuery` 는 기본값.
- 부품: BasePart 마다 `PartIndex` 어트리뷰트 1..`FacilityConfig.partCount(id)`. 부품 1 = 바닥·벽, 2 = 지붕 또는 문틀, 3·4 = 가구. 빈 부품이 없어야 한다(`BuildKit.assertPartIndex(model, count)`).
- 색·재질: 시설마다 고정값(옛 스킨 A)이다. 스킨(색 바꾸기)은 2026-09-29 사용자 결정으로 폐기해 `SkinRole`·재도색이 없다.
- 좌석: `Seats` 폴더에 Attachment `S01…`. 위치 = 의자 아래 **바닥** 중심(방 바닥 높이), LookVector(-Z) = 학생이 보는 방향. 의자 앉는 면 높이 1.55, 책상 상판 2.875 (`CharacterBuilder.SIT_HIP/SIT_DESK`).
- 좌석이 있는 모델은 Attachment `Door` 하나(문 중심 바닥, LookVector 가 방 안쪽). desk 모델의 Door 는 교실1 남문 (-60,0,-32.5).
- principal: Roblox `Seat` 인스턴스 "PrincipalChair" (60,-10) 앉는 면 1.55, Disabled=false. 손님 자리 S01 (50,-2.5).
- auditorium: 바닥 y=18, 좌석 S01…S25(S25 예약), 단상 (0,-32.5) 위 Part "GraduationBell".
- 문 폭 ≥8. 벽 두께 1, 높이 18(방, 체육관 20), 지붕 두께 1. 미건설 부지는 평평한 바닥(Shell 바닥이 이미 있으므로 아무것도 안 둔다).
