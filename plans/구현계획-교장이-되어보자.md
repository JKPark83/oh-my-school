### 3.2 서버 서비스 API

```lua
DataService
  .Start()                              -- 스토어 준비
  .load(player) -> Profile?             -- 실패 시 Kick
  .get(player) -> Profile?
  .save(player) -> boolean              -- 즉시 저장
  .saveDebounced(player, seconds)
  .release(player)
  .markDirty(player)                    -- ProfileSync 예약 (≤1Hz, seq 단조)
  .syncNow(player)                      -- 즉시 ProfileSync

PlotService
  .Start()                              -- Workspace.Plots / ReplicatedStorage.PlotState 확인, Touched 배선, 팻말/경계 처리
  .assign(player) -> plotId?            -- 빈 번호 중 최소. 다 차면 nil
  .release(player)
```

### 3.6 Geometry 빌더 규약

- `build(plotCFrame: CFrame): Model`. 모델 이름 = facilityId. 좌표는 `FacilityConfig.BY_ID[id]` 의 center/size/pad 를 쓴다(부지 로컬). 월드 변환: `local cf = plotCFrame * CFrame.new(localPos) * localRot` → `BuildKit.part(parent, name, size, cf.Position, { cframe = cf.Rotation, ... })`.
- 파트 ≤25, 전부 `BuildKit.part`. 벽·지붕은 `fade = true`. `CanQuery` 는 기본값.
- 부품: BasePart 마다 `PartIndex` 어트리뷰트 1..`FacilityConfig.partCount(id)`. 부품 1 = 바닥·벽, 2 = 지붕 또는 문틀, 3·4 = 가구. 빈 부품이 없어야 한다(`BuildKit.assertPartIndex(model, count)`).
- 색·재질: 시설마다 고정값(옛 스킨 A)이다. 스킨(색 바꾸기)은 2026-09-29 사용자 결정으로 폐기해 `SkinRole`·재도색이 없다.
- 좌석: `Seats` 폴더에 Attachment `S01…`. 위치 = 의자 아래 **바닥** 중심(방 바닥 높이), LookVector(-Z) = 학생이 보는 방향. 의자 앉는 면 높이 1.55, 책상 상판 2.875 (`CharacterBuilder.SIT_HIP/SIT_DESK`).
- 좌석이 있는 모델은 Attachment `Door` 하나(문 중심 바닥, LookVector 가 방 안쪽). desk 모델의 Door 는 교실1 남문 (-60,0,-32.5).
- principal: Roblox `Seat` 인스턴스 "PrincipalChair" (60,-10) 앉는 면 1.55, Disabled=false. 손님 자리 S01 (50,-2.5).
